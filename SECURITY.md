# Security Policy

TriggerDesk is currently an experimental Rialo DevNet application. The checked-in
V1 programs update workflow state but do not transfer RLO. Do not use them for
real-value payments.

Report vulnerabilities privately to the repository owner through GitHub's
private vulnerability reporting feature. Do not open a public issue containing
exploitable details, keys, mnemonics, or signed transaction material.

Security fixes receive priority by impact. No release is production-ready until
fund movement, authorization, replay safety, cancellation/refunds, external
wallet support, an independent contract audit, and the production Rialo network
have all been verified with evidence.
